# World Region Master (Phase 10)

The authoritative list of world regions, derived read-only from the real
`Data.pk2 /RegionInfo.txt` (SHA-256
`787d9b417cf3044ff9260f484656002089f7406afd57f229a3c5ac85460739ff`).

Machine-readable table: `WORLD_REGION_MASTER.csv` (generated by
`scripts/build_world_android.py`).
Committed Android copy: `android/app/src/main/assets/game/world/world_regions.tsv`
(same rows, TSV, with provenance header).

## Schema

`type, name, code, sx0, sx1, sy0, sy1, ref_sx, ref_sy, cells`

- `type`: `FIELD` or `TOWN` (as in RegionInfo.txt).
- `name`: the section name.
- `code`: region code token (dungeon links), empty for open-world fields.
- `sx0..sy1`: bounding window of the real RegionInfo cells. Windows are
  bounding boxes and may include water/non-walkable sectors.
- `ref_sx, ref_sy`: the minimum (sx, sy) cell — the reference sector used for
  world-relative coordinates of this region.
- `cells`: number of sector cells listed in RegionInfo.txt for the section.
