# Web Runtime Audit — Phase 22 Native Android Migration

Date: 2026-08-31
Scope: inventory + classification of every WebView / Capacitor / browser-runtime
component before any deletion or refactor. This is the required gate for Phase 22
("remove WebView/Capacitor, replace with native runtime"). Nothing is deleted until
this classification is complete.

Verification conventions match the rest of the repo:
- **VERIFIED** — an actual file in the workspace was inspected this session.
- **NOT VERIFIED** — claimed but not re-inspected; treated as unproven.
- No behavior, format, or protocol is invented.

---

## 1. What "WebView/Capacitor runtime" means here

The Android app currently launches `MainActivity`, which extends Capacitor's
`BridgeActivity`. `BridgeActivity` hosts a `WebView` and loads the built web game
(`capacitor.config.ts` → `webDir: "map/dist"`). So today's Android "game" is the
Vite/Three.js web app running inside a WebView. That is the thing Phase 22 removes
as the Android game runtime.

The `map/` web app itself is a separate product (the browser map + web game). It is
NOT deleted. It is only dismounted as the Android runtime.

## 3. Five-bucket classification

Buckets per Phase 22 directive:
1. **SOURCE** — required source-of-truth / conversion tooling. Keep.
2. **REUSABLE** — reusable non-runtime tooling. Keep (relocate if it breaks nothing).
3. **OBSOLETE-WEB** — obsolete web/WebView runtime. Remove from the Android runtime.
4. **DUPLICATE** — duplicate of a native implementation. Remove.
5. **DEAD** — unreferenced. Remove (after reference check).

## 4. Migration plan (order matters)

1. Repoint `AndroidManifest.xml` launcher intent-filter from `MainActivity` to
   `game.GameActivity`.
2. Rewrite `MainActivity.java` as a plain `android.app.Activity` that redirects to
   `GameActivity` (removes the `BridgeActivity`/WebView dependency without deleting
   the class file).
3. Strip Capacitor from `android/app/build.gradle` and `android/settings.gradle`.
4. Relocate Capacitor config/scaffold artifacts to `legacy/capacitor/` (move, not
   delete): `capacitor.config.ts`, `package-lock.json`,
   `android/app/capacitor.build.gradle`, `android/capacitor.settings.gradle`,
   the two getcapacitor example tests.
5. Trim `package.json` to drop Capacitor deps/scripts.
6. Implement the native runtime core: frame driver (drives `GameLoop`), input
   controller (touch → camera + movement intents), wired into `GameActivity`.
7. Verify: compile pure-JVM classes + run JVM tests; structural scan of
   Android-bound classes. No APK build (no Android SDK/Gradle in this environment).

---

## 5. Verification limits (this environment)

- JDK 17 `javac`/`java` available; pure-JVM classes compile and tests run.
- No Android SDK, no Gradle, no emulator → APK build and instrumented tests are
  NOT EXECUTED. Android-bound classes (Activity/View) get structural checks only.
- `map/` web build (`deno task build`) is unchanged and not re-run as part of the
  Android runtime removal (it is the web product, not the Android runtime).
